#Description
This program asks the user for the number of notebooks that are needed to be packed and how many each box can hold, if the number of each box can hold is greater than than the total amount of notebooks, it will say so.

#Variable names
notebook_count = total amount of notebooks that are needed to be packed.
box_count = total number of notebooks that each box can hold.

#Sample input 1
notebook_count = 60
box_count = 9

#Sample input 2
notebook_count = 5
box_count = 20

#Sample output 1
The total number of boxes that can be filled is  6
And there will be  6 left over.

#Sample output 2
It cannot fill a full box, so 5 will go to the loose pack.
